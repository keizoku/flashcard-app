# 機能の設計

各機能が「何をするか」と「どう判定・計算しているか」。画面の操作手順は [../README.md](../README.md)。

## 1. デッキ

- 作成（`app/actions.js` `addDeck`）: 名前（100文字まで）、YouTube の URL、字幕、タグ。名前が空で URL があれば動画タイトルを使う。
  字幕があれば取り込み画面へ、なければデッキ画面へ移る
- 編集・削除（`app/decks/[id]/edit/actions.js`）、一覧での複数削除（`deleteDecks`、1000個まで）
- 一覧（`app/page.js`）: カード数、今日出すカード数、タグ、動画の理解度。タグの絞り込みは AND 条件（画面側で絞る）

### タグ（`lib/tags.js`）
- 入力はカンマ（`,` `、` `，`）区切り、または JSON の配列。空白をまとめ、大文字小文字を無視して重複を除く
- 1つ20文字まで（`MAX_TAG_LENGTH`）、1デッキ10個まで（`MAX_TAGS_PER_DECK`）
- タグの名前は全ユーザーで共有するが、一覧に出すのは自分のデッキに付いたものだけ（`getAllTags(userId)`）。
  どのデッキにも付いていないタグは、保存のたびに消す

## 2. 字幕の解析（`lib/transcript.js`）

字幕から「知らない語がちょうど n 個（n = 1〜3）の文」を探す。i+1 の考え方（今の力より1つだけ難しいものを覚える）。

### 2.1 区間に分ける（`parseSegments`）
YouTube の「文字起こしを表示」からコピーした、次の形を受け付ける。
- 時刻と文が別の行（`0:03` / `hello everyone`）
- 時刻・読み上げ用テキスト・本文がくっついた行（`0:066 secondsnew youtube account` → 6秒、`new youtube account`）。
  英語（`1 minute, 4 seconds`）と日本語（`1 分 4 秒`）の読み上げ用テキストを取り除く
- `[0:06] 文` の形（AI で整えた字幕）

取り除くもの: `[Music]` などの角かっこ（時刻は残す）、`>>`、チャプター名、読み上げ用テキストだけの行、末尾の画面の文字（`Sync to video time` 以降）。
時刻のない行は、前の時刻を引き継ぐ。

### 2.2 文に分ける
- 句読点がある字幕: `. ! ?` で文に分ける
- 句読点がほとんどない字幕（1文の平均が40語を超える、`lacksPunctuation`）: 接続詞（so, and, but, because …）の前などで仮に区切る（`mode: "heuristic"`）。
  6語未満では切らず、30語を超えたら必ず切る。完結した文にはならないので、画面で「チャット AI で文を整える」を勧める
- AI で整えた文がデッキに保存されていて、字幕が変わっていなければ、それを使う（`mode: "ai"`、[5](#5-チャット-ai-との連携)）

### 2.3 知らない語を数える
- 語は原形にまとめて数える（`lib/vocab.js`）。`data/en-words.txt`（単語の形の頻出順）を、原形ごとの順位に作り直したものを使う。
  活用形は、より頻出の原形にまとめる（ran → run）。短縮形は元の語にする（don't → do）
- **知っている語** = 頻出順位がレベルの語彙数以内の語 ＋ 「知ってる」を押した語 ＋ 学習で「覚えた」カードの語（`getWordState`）
- 数えない語: 1文字の語、文の途中で大文字で始まる語・全部大文字の語（人名・略語とみなす）、文頭でも字幕のほかの所で文中に大文字で出てくる語
- イディオム・句動詞は `data/idioms.tsv` で照合し、1つの語として数える（`lib/idioms.js`）。
  活用形も一致し（bit the bullet → bite the bullet）、`sth` / `sb` の所には3語まで入ってよい（figured it out → figure sth out）。
  重なるときは長い表現を優先する。イディオムの目安の語彙数がレベル以内なら知っているとみなす

### 2.4 段階に分ける（`analyzeTranscript`）
- 段階 n（i+n）= 新しく覚える語がちょうど n 個（1〜3、`MAX_STAGE`）の文
- 候補にしない文: 4語未満・40語を超える文（`MIN_WORDS` / `MAX_WORDS`）、同じ文の2回目以降、**学習中の語**（カードにしたがまだ覚えていない語）を含む文（覚えるまで保留）
- **理解度** = すべての文のうち、知らない語が0個の文の割合（短い文・長い文も含む）。学習中の語だけが残っている文は「もう少し」（`waiting`）
- AI で整えた文なら、和訳と語句の意味（`findGloss`）、和訳の中の対応部分（和訳に実際に含まれるときだけ）を候補に付ける

## 3. カード

- 候補から登録（`app/decks/[id]/import/actions.js` `registerCards`、一度に200枚まで）: i+2・i+3 の文は、覚えたい語を2〜3個持つ1枚のカードにする。
  覚えたい語の形は文の中にあること、見出しは小文字の英語（`/^[a-z]+(?:[' -][a-z]+)*$/`）であることを確かめる
- 手で追加（`addCard`）: 表と裏（各500文字まで）
- 編集（`app/cards/[id]/edit/actions.js`）: 覚えたい語は3つまで。形は表の文の中、和訳の対応部分は和訳の中の文字であること。例文は「英文 | 和訳」を1行ずつ、10個まで
- 「知ってる」（`markKnown`）: その語を知っている語に足す。設定画面から取り消せる
- カードの覚えたい語は `card_targets` が正。1つ目は `cards.target_*` にもコピーする（`replaceCardTargets`）

## 4. 記憶テスト

`lib/review.js`、`app/decks/[id]/study/`。ライトナー方式（段階ごとに間隔を延ばす）。

| 段階（`review_box`） | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 次に出すまで（`INTERVAL_DAYS`） | 0日 | 1日 | 3日 | 1週間 | 2週間 | 1か月 | 2か月 |

- 「覚えている」→ 段階を1つ上げる（6で止まる、`MAX_BOX`）。「覚えていない」→ 段階0（`lapse_count` を1増やす）
- 次に出す日時 = その段階の日数だけあとの日の**朝4時（日本時間）**（`nextDueSql`）。日付は朝4時に変わる
  （`DAY_START_HOUR`、`TIME_ZONE`）。夜ふかしして深夜1時に学習しても前の日の続きとして数えるので、
  1日のカードはその日の朝4時に出る。0日（覚えていない）はすぐ。
  ぴったり24時間待つより「次の日になったら出る」ほうが、毎日の学習の感覚に合うため
- 今日出すカード = 一度も学習していないか、次に出す日時を過ぎたもの（`DUE_CONDITION`）
- 出す順: 期限を過ぎたもの（古い順）→ 未学習（登録順）。「覚えていない」カードは、その回の最後にもう一度出す（画面側）
- 前のカードに戻ると、そのカードへの答えを取り消す（`undoReview`）。答える前の値を `review_logs` に残してあり、それに戻す。
  取り消せるのは、そのカードの最新の記録だけ
- キーボード: 表の面 → で答えを見る・← で前のカードへ、答えの面 ← 覚えていない・→ 覚えている、↑ で読み上げ（Shift+↑ でゆっくり）

### 覚え具合の区分（`STATUS_SQL`、統計で使う）
| 区分 | 条件 |
| --- | --- |
| 覚えた（learned） | 段階3以上（`LEARNED_BOX`、3回続けて「覚えている」） |
| 覚え中（learning） | 段階1〜2 |
| 覚えていない（forgot） | 段階0で、答えたことがある |
| 未学習（new） | 答えたことがない |

## 5. チャット AI との連携

API は使わない。アプリがプロンプトを作り、ユーザーがチャット AI に送って、答えを貼り付ける。
答えの読み取りは、多少形が崩れていても読めるようにする（コードブロックの記号、`-` の箇条書き、全角のコロン・縦棒・イコールなど）。

### 5.1 字幕を文に整える（`lib/sentences.js`）
- プロンプト（`buildSentencePrompts`）: 句読点と大文字小文字を整え、フィラー・言葉の重なり・言い直し・明らかな聞き間違いだけを直す（言い換え・文法の修正はしない。リスニングに使うため）。
  各文に時刻、和訳、語句の意味（`語句 = 品詞「意味」【和訳の対応部分】`）、直したら元の字幕。字幕は1,200語ごとに分ける
- 答え（`parseAiSentences`）: `[分:秒] 文` の行と、続く `訳:` `語句:` `元:` の行。時刻のない英語の行は前の文の続き
- 取り込み（`importSentences`）: 文をデッキに保存（字幕の sha256 と一緒に）。登録済みのカードは、言葉の6割以上が重なる文（時刻が15秒以内なら優先）に結びつけ、
  例文・時刻・和訳・語句の意味を新しい文のもので上書きする（覚えたい語が新しい文に見つからないカードは上書きしない）

### 5.2 カードの解説（`lib/cardPrompts.js`）
- 解説が足りないカード（例文も豆知識もない、または和訳の対応部分がない語がある）を、一度に20枚まで（`MAX_CARDS_PER_PROMPT`）
- 答えは `### カードID` ごとに `和訳:` `対応:` `意味:` `例文:`（英文 | 和訳）`豆知識:`。覚えたい語が複数なら `対応:` `意味:` を `語句 = 内容` で語ごとに
- 取り込み（`importCardExplanations`）: そのデッキのカードだけ更新する。対応部分は和訳の中にあるときだけ使う。各項目2,000文字まで、例文は5個まで

## 6. 覚えた語で物語を作る（`lib/story.js`、`lib/storyPrompt.js`）

- 語を選ぶ（`getWordPool`）: 覚えた語（段階3以上）/ 学習中の語 / 両方、デッキで絞れる。3〜40語をランダムに選ぶ
- プロンプト: 長さ（150 / 300 / 500語）、テーマ、レベル。答えは `タイトル:` と `[番号] 英文` の行、`訳:` `語句:`
- 取り込み（`createStoryDeck`）: 「物語: タイトル」のデッキ（`kind = 'story'`、タグ「物語」）を作り、選んだ語が入っている文を、その語（1文に3つまで）を覚えたい語にしたカードにする。
  イディオムは `語句:` に書かれた形を手がかりに探す
- 物語のデッキでは、本文を通して読める（使った語の強調、和訳の切り替え、全文の読み上げ）

## 7. 統計（`app/stats/page.js`）

すべて自分のデッキだけを集計する。
- 覚え具合の区分ごとの枚数と割合、デッキ別の内訳
- 直近14日の、日ごとの「覚えている / 覚えていない」の回数（日本時間で区切る）
- 苦手な語: 「覚えていない」の回数が多い順に15件
- 区分ごとの語の一覧

## 8. レベル設定（`app/settings/`、`lib/levels.js`）

- 英検（3級〜1級）・TOEIC（〜400点〜900点〜）から選ぶと、語彙数の目安（2,000〜12,000語）が決まる。直接指定なら100〜30,000の整数
- 設定がなければ英検2級（5,000語）
- 保存したあとも、選んだレベル・入れた数をそのまま出す（フォームは `onSubmit` で送る。`action` で送ると、React がフォームを開いたときの値に戻してしまうため）
- 読み上げ（声・速さ・自動で読み上げ）は端末ごとに違うので、DB ではなくブラウザの localStorage に保存する

## 9. 読み上げ（`app/components/speech.js`）

- ブラウザの Web Speech API。英語の声だけを出し、効果音のような声は除く。同じ名前の声は1つにまとめる（端末内の声を優先）
- 声の選び方: 保存した声 → 自然な声（Samantha、Alex、Ava、Google US English …）→ en-US の声

## 10. デッキの共有（`lib/sharing.js`、`app/shared/`）

自分のデッキを公開すると、ログインしているほかのユーザーが「みんなのデッキ」（`/shared`）で見て、自分のデッキとして取り込める。

- 表示名（`users.display_name`）: アカウントの画面で決める。前後の空白を除き、30文字まで。制御文字は使えない。
  公開したデッキに、作った人として出す。**メールアドレスはほかの人に見せない**。公開中のデッキがある間は空にできない
  ヘッダーの右上にも、メールアドレスではなく表示名を出す（決めていなければ「アカウント」）
- 公開する（デッキの編集の画面、`setDeckPublished`）: 表示名と、1枚以上のカードが要る。`decks.published_at` に公開した日時を入れる
  （公開中にもう一度押しても変えない）。公開をやめると NULL。自分のデッキだけ
- みんなのデッキ（`listPublicDecks`）: 公開中のデッキを、新しく公開した順に。デッキ名・表示名・公開日・枚数・タグ。
  自分のデッキには「自分のデッキ」、取り込んだことがあれば「取り込みずみ」と出す
- デッキの中身（`/shared/[id]`、`getPublicDeck`）: カードの例文・和訳・覚えたい語・裏のメモ。公開していないデッキは 404。
  持ち主の学習の状態は見せない
- 取り込む（`copyPublicDeck`）: **その時点の内容をコピー**して、取り込んだ人の新しいデッキにする（1つのトランザクション）
  - コピーするもの: デッキの名前・動画・字幕・AI で整えた文・物語の語、タグ、カードの例文・裏・解説（和訳・意味・例文・豆知識）・動画の時刻、覚えたい語
  - コピーしないもの: 記憶テストの状態（未学習から始める）、学習の記録、公開の状態
  - 元のデッキとはつながらない。あとで元を変えても・公開をやめても・消しても、コピーは変わらない
  - 取り込み元は `decks.source_deck_id` に残す（「取り込みずみ」の表示用。元を消すと NULL）。もう一度取り込むと、別のデッキになる
  - 自分のデッキ・公開していないデッキは取り込めない

## 11. ホームページ（`app/landing/`）

ログインしていない人がトップ（`/`）を開くと、アプリの紹介を出す（ログインしていればデッキの一覧）。

- 内容: はじめの画面（キャッチコピーと「無料で始める」）、よくある悩み、i+1 の説明、使い方の4ステップ、機能、1日の流れ、よくある質問、最後の呼びかけ
- 見本のカード（`DemoCard.js`）: 学習の画面と同じ流れ（答えを見る → 覚えている / 覚えていない）を、決まった3枚でさわれる。DB には何も保存しない
- アプリでできることだけを書く。利用者の数・声などの数字は作らない
- 色は `.lp` の中だけで決める（`landing.css`）。ダークモード・スマートフォンの幅に対応


## 12. 動画を探す（`app/search/`、`lib/videoFilter.js`）

学習に使う動画を、**みんなが学んだ動画（13 のおすすめ）の中から**探す画面（ヘッダーの「動画を探す」、`/search`）。
YouTube の検索はしない（YouTube の API キーも使わない）。

- 絞り込み（`filterVideos`）: 画面の中で、その場で絞る（サーバーにも YouTube にも問い合わせない）。並び順（レベルに合う順）は変えない
  - キーワード: タイトルかチャンネル名に入っているもの。大文字・小文字は区別しない。空白で区切ると、全部が入っているもの
  - レベル: ちょうどいい / やさしい / むずかしい
  - 長さ: 3分未満 / 3〜20分 / 20分より長い（字幕の最後の時刻から出した長さ。わからない動画は、長さを指定したときは出さない）
- 探せる動画がまだないときは、YouTube で好きな動画を見つけて、URL を「新しいデッキ」に貼るように案内する
- 「この動画でデッキを作る」: 新しいデッキの画面を、URL とデッキ名（動画のタイトル）を入れた状態で開く（`/decks/new?video=ID&name=...&back=/search`）。
  字幕の欄を開き、字幕のコピーのしかたと動画へのリンクを出す。「動画を探すに戻る」で戻る（戻り先は `/search` だけ受け付ける）

## 13. おすすめの動画（`lib/recommend.js`）

「動画を探す」の画面（12）に出す。**ほかの人が字幕を入れてデッキにした動画**を、
自分のレベルと覚えた語で解析して、理解度の合う順に並べる。YouTube の API キーは使わない。

- 候補（`listCandidateVideos`）: 動画と字幕のあるデッキ（物語のデッキは除く）の動画。自分のデッキにある動画は除く。
  学んだ人の多い順・新しい順に100本まで。字幕は、その動画のデッキのうち、いちばん長いものを使う（自分の字幕は使わない）
- タイトル（`refreshVideoInfo`）: YouTube の oEmbed（API キー不要）でタイトル・チャンネル名を取り、`videos` テーブルに入れる（7日たったら取り直す。8本ずつ同時に）。
  非公開・消された動画は oEmbed で取れないので、見られない（`available = false`）にして出さない。つながらないときは前の情報を残し、まだ情報がなければ出さない
- **限定公開の動画は、公開動画と見分けられない**（API を使わないため）。URL を知っている人だけが見られる動画が、ほかの人のおすすめに出ることがある
- 出すもの: YouTube のタイトル・チャンネル、長さの目安（字幕の最後の時刻）、学んだ人数、自分の理解度。**デッキ名・誰のデッキかは出さない**。字幕もほかの人には見せない
- 理解度: 字幕を自分のレベル（語彙数）・知っている語・学習中の語で解析した、全部わかる文の割合。文が10より少ない字幕は出さない
- レベルに合うか（`fitOf`）: 85%以上 = やさしい、50〜84% = ちょうどいい、50%未満 = むずかしい
- 並び順（`rankRecommendations`）: ちょうどいい（新しい語が1つの文が多い順）→ やさしい（むずかしめの順）→ むずかしい（やさしめの順）
