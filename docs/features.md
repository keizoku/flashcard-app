# 機能の設計

各機能が「何をするか」と「どう判定・計算しているか」。画面の操作手順は [../README.md](../README.md)。

## 1. 単語帳

- 作成（`app/actions.js` `addDeck`）: 名前（100文字まで）、YouTube の URL、字幕、タグ。名前が空で URL があれば動画タイトルを使う。
  字幕があれば取り込み画面へ、なければ単語帳画面へ移る
- 編集・削除（`app/decks/[id]/edit/actions.js`）、一覧での複数削除（`deleteDecks`、1000個まで）
- 一覧（`app/page.js`）: カード数、今日出すカード数、タグ、動画の理解度。タグの絞り込みは AND 条件（画面側で絞る）。
  絞り込みのタグの候補は件数の多い順、同じ件数なら文字コード順（`lib/tagCandidates.js`。言語の設定で並びを変えず、サーバーとブラウザで画面を食い違わせない）
- 一覧では、覚えた単語で作った物語の単語帳（`decks.kind = 'story'`）に淡いむらさきの色と「物語」の印を付けて、ほかの単語帳と区別する

### タグ（`lib/tags.js`）
- 入力はカンマ（`,` `、` `，`）区切り、または JSON の配列。空白をまとめ、大文字小文字を無視して重複を除く
- 1つ20文字まで（`MAX_TAG_LENGTH`）、単語帳1冊に10個まで（`MAX_TAGS_PER_DECK`）
- タグの名前は全ユーザーで共有するが、一覧に出すのは自分の単語帳に付いたものだけ（`getAllTags(userId)`）。
  どの単語帳にも付いていないタグは、保存のたびに消す

## 2. 字幕の解析（`lib/transcript.js`）

字幕から「知らない語がちょうど n 個（n = 1〜3）の文」を探す。i+1 の考え方（今の力より1つだけ難しいものを覚える）。

### 2.1 区間に分ける（`parseSegments`）
YouTube の「文字起こしを表示」からコピーした、次の形を受け付ける。
- 時刻と文が別の行（`0:03` / `hello everyone`）
- 時刻・読み上げ用テキスト・本文がくっついた行（`0:066 secondsnew youtube account` → 6秒、`new youtube account`）。
  英語（`1 minute, 4 seconds`）と日本語（`1 分 4 秒`）の読み上げ用テキストを取り除く
- `[0:06] 文` の形（AI で整えた字幕）

取り除くもの: `[Music]` などの角かっこ（時刻は残す）、`>>`、チャプター名、読み上げ用テキストだけの行、末尾の画面の文字（`Sync to video time` 以降）。
時刻のない行は、前の時刻を引き継ぐ。

### 2.2 文に分ける
- 句読点がある字幕: `. ! ?` で文に分ける
- 句読点がほとんどない字幕（1文の平均が40語を超える、`lacksPunctuation`）: 接続詞（so, and, but, because …）の前などで仮に区切る（`mode: "heuristic"`）。
  6語未満では切らず、30語を超えたら必ず切る。完結した文にはならないので、画面で「チャット AI で文を整える」を勧める
- AI で整えた文が単語帳に保存されていて、字幕が変わっていなければ、それを使う（`mode: "ai"`、[5](#5-チャット-ai-との連携)）

### 2.3 知らない語を数える
- 語は原形にまとめて数える（`lib/vocab.js`）。`data/en-words.txt`（単語の形の頻出順）を、原形ごとの順位に作り直したものを使う。
  活用形は、より頻出の原形にまとめる（ran → run）。短縮形は元の語にする（don't → do）
- **知っている語** = 頻出順位がレベルの語彙数以内の語 ＋ 「知ってる」を押した語 ＋ 学習で「覚えた」カードの語（`getWordState`）
- 数えない語: 1文字の語、文の途中で大文字で始まる語・全部大文字の語（人名・略語とみなす）、文頭でも字幕のほかの所で文中に大文字で出てくる語
- イディオム・句動詞は `data/idioms.tsv` で照合し、1つの語として数える（`lib/idioms.js`）。
  活用形も一致し（bit the bullet → bite the bullet）、`sth` / `sb` の所には3語まで入ってよい（figured it out → figure sth out）。
  重なるときは長い表現を優先する。イディオムの目安の語彙数がレベル以内なら知っているとみなす

### 2.4 段階に分ける（`analyzeTranscript`）
- 段階 n（i+n）= 新しく覚える語がちょうど n 個（1〜3、`MAX_STAGE`）の文
- 候補にしない文: 4語未満・40語を超える文（`MIN_WORDS` / `MAX_WORDS`）、同じ文の2回目以降、**学習中の語**（カードにしたがまだ覚えていない語）を含む文（覚えるまで保留）
- **理解度** = すべての文のうち、知らない語が0個の文の割合（短い文・長い文も含む）。学習中の語だけが残っている文は「もう少し」（`waiting`）
- AI で整えた文なら、和訳と語句の意味（`findGloss`）、和訳の中の対応部分（和訳に実際に含まれるときだけ）を候補に付ける

## 3. カード

- 候補から登録（`app/decks/[id]/import/actions.js` `registerCards`、一度に200枚まで）: i+2・i+3 の文は、覚えたい語を2〜3個持つ1枚のカードにする。
  覚えたい語の形は文の中にあること、見出しは小文字の英語（`/^[a-z]+(?:[' -][a-z]+)*$/`）であることを確かめる
- 手で追加（`addCard`）: 表と裏（各500文字まで）
- 編集（`app/cards/[id]/edit/actions.js`）: 覚えたい語は3つまで。形は表の文の中、和訳の対応部分は和訳の中の文字であること。例文は「英文 | 和訳」を1行ずつ、10個まで
- 「知ってる」（`markKnown`）: その語を知っている語に足す。設定画面から取り消せる
- カードの覚えたい語は `card_targets` が正。1つ目は `cards.target_*` にもコピーする（`replaceCardTargets`）

## 4. 記憶テスト

`lib/review.js`、`app/decks/[id]/study/`。ライトナー方式（段階ごとに間隔を延ばす）。

| 段階（`review_box`） | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 次に出すまで（`INTERVAL_DAYS`） | 0日 | 1日 | 3日 | 1週間 | 2週間 | 1か月 | 2か月 |

- 「覚えている」→ 段階を1つ上げる（6で止まる、`MAX_BOX`）。「覚えていない」→ 段階0（`lapse_count` を1増やす）
- 次に出す日時 = その段階の日数だけあとの日の**朝4時（日本時間）**（`nextDueSql`）。日付は朝4時に変わる
  （`DAY_START_HOUR`、`TIME_ZONE`）。夜ふかしして深夜1時に学習しても前の日の続きとして数えるので、
  1日のカードはその日の朝4時に出る。0日（覚えていない）はすぐ。
  ぴったり24時間待つより「次の日になったら出る」ほうが、毎日の学習の感覚に合うため
- 今日出すカード = 一度も学習していないか、次に出す日時を過ぎたもの（`DUE_CONDITION`）
- 出す順: 期限を過ぎたもの（古い順）→ 未学習（登録順）。「覚えていない」カードは、その回の最後にもう一度出す（画面側）
- 前のカードに戻ると、そのカードへの答えを取り消す（`undoReview`）。答える前の値を `review_logs` に残してあり、それに戻す。
  取り消せるのは、そのカードの最新の記録だけ
- キーボード: 表の面 → で答えを見る・← で前のカードへ、答えの面 ← 覚えていない・→ 覚えている、↑ で読み上げ（Shift+↑ でゆっくり）
- スワイプ（iPhone・iPad など、キーボードのない端末）: 左右のスワイプを ← / → キーの代わりにする（`lib/swipe.js`、`app/components/useSwipeKeys.js`）。
  向きはキーと同じ（指を右へ = →: 答えを見る・覚えている、左へ = ←: 前のカードへ・覚えていない）。
  横に 50px（`MIN_SWIPE_PX`）以上、0.8秒（`MAX_SWIPE_MS`）以内、縦の動きが横の6割以下のときだけ。短い動き・ゆっくりの動き・縦のスクロールはなにもしない。
  入力欄・動画の上から始めた動きは無視する。タッチの操作だけを見るので、パソコンのマウスでは動かない。
  タッチの端末（`(hover: none) and (pointer: coarse)`）では、カードの下にスワイプの案内を出す

### 覚え具合の区分（`STATUS_SQL`、統計で使う）
| 区分 | 条件 |
| --- | --- |
| 覚えた（learned） | 段階3以上（`LEARNED_BOX`、3回続けて「覚えている」） |
| 覚え中（learning） | 段階1〜2 |
| 覚えていない（forgot） | 段階0で、答えたことがある |
| 未学習（new） | 答えたことがない |

## 5. チャット AI との連携

API は使わない。アプリがプロンプトを作り、ユーザーがチャット AI に送って、答えを貼り付ける。
答えの読み取りは、多少形が崩れていても読めるようにする（コードブロックの記号、`-` の箇条書き、全角のコロン・縦棒・イコールなど）。

### 5.1 字幕を文に整える（`lib/sentences.js`）
- プロンプト（`buildSentencePrompts`）: 句読点と大文字小文字を整え、フィラー・言葉の重なり・言い直し・明らかな聞き間違いだけを直す（言い換え・文法の修正はしない。リスニングに使うため）。
  各文に時刻、和訳、語句の意味（`語句 = 品詞「意味」【和訳の対応部分】`）、直したら元の字幕。字幕は1,200語ごとに分ける
- 答え（`parseAiSentences`）: `[分:秒] 文` の行と、続く `訳:` `語句:` `元:` の行。時刻のない英語の行は前の文の続き
- 取り込み（`importSentences`）: 文を単語帳に保存（字幕の sha256 と一緒に）。登録済みのカードは、言葉の6割以上が重なる文（時刻が15秒以内なら優先）に結びつけ、
  例文・時刻・和訳・語句の意味を新しい文のもので上書きする（覚えたい語が新しい文に見つからないカードは上書きしない）

### 5.2 カードの解説（`lib/cardPrompts.js`）
- 解説が足りないカード（例文も豆知識もない、または和訳の対応部分がない語がある）を、一度に20枚まで（`MAX_CARDS_PER_PROMPT`）
- 答えは `### カードID` ごとに `和訳:` `対応:` `意味:` `例文:`（英文 | 和訳）`豆知識:`。覚えたい語が複数なら `対応:` `意味:` を `語句 = 内容` で語ごとに
- 取り込み（`importCardExplanations`）: その単語帳のカードだけ更新する。対応部分は和訳の中にあるときだけ使う。各項目2,000文字まで、例文は5個まで

## 6. 覚えた語で物語を作る（`lib/story.js`、`lib/storyPrompt.js`）

- 語を選ぶ（`getWordPool`）: 覚えた語（段階3以上）/ 学習中の語 / 両方、単語帳で絞れる。3〜40語をランダムに選ぶ
- プロンプト: 長さ（150 / 300 / 500語）、テーマ、レベル。答えは `タイトル:` と `[番号] 英文` の行、`訳:` `語句:`
- 取り込み（`createStoryDeck`）: 「物語: タイトル」の単語帳（`kind = 'story'`、タグ「物語」）を作り、選んだ語が入っている文を、その語（1文に3つまで）を覚えたい語にしたカードにする。
  イディオムは `語句:` に書かれた形を手がかりに探す
- 物語の単語帳では、本文を通して読める（使った語の強調、和訳の切り替え、全文の読み上げ）
- スライド（`app/decks/[id]/StorySlides.js`、「スライドで見る」）: 画面いっぱいに、1枚目は題名と使った単語、そのあと1文ずつ大きく出す。
  使った語を強調し、その文の語を下に出す。和訳は切り替えで出す。
  - 自動再生: 今の文を読み上げ、読み終わったら 1.2 秒あけて次の文へ。最後の文を読み終わったら止まる（最後まで見たあとは最初の文から）
  - キーボード: ← → で前後、スペースで自動再生 / 止める、↑ で今の文を読み上げ（文をクリックしても読む）、Esc で閉じる。「全画面」でブラウザの全画面にできる
  - スワイプ（iPhone・iPad）: 本のページと同じ向き（指を左へ = 次の文、右へ = 前の文）。題名のスライドの案内も、タッチの端末ではスワイプの説明にする
  - 自動再生している間を、この単語帳のリスニングの時間として記録する（12）
  - 場面の絵があれば、文の上に出す（題名のスライドには最初の場面の絵）。次の場面の絵は先に読み込んでおく
- 場面の絵（`lib/scenes.js`、`app/decks/[id]/StoryScenes.js`）: YouTube から作った単語帳には動画があるが、物語にはないので、代わりに場面ごとの絵を出す
  - 場面: 物語の単語帳を初めて開いたときに、文を4文くらいずつ（数をなるべく同じに）の場面に分ける（`story_scenes`）
  - 絵の指示文: 初めは「絵のスタイル（文字なしの、水彩の絵本風）＋場面の英文」（600文字まで、単語の切れ目で切る）。直せる（1〜1000文字）。コピーできる
  - 画像を取り込む: 指示文を画像を作れる AI（ChatGPT・Gemini・Copilot など）に貼って作った画像を取り込む（`POST /api/scenes/[id]/image`）。
    PNG・JPEG・WebP・GIF、5MB まで。種類はファイルの中身で見分ける（SVG などは受け付けない）。ほかのサイトからの送信は受け付けない
  - 自動で作る: 無料の画像生成サービス（Pollinations、キー不要）に指示文を送って作る（`lib/imageGen.js`、90秒まで待つ）。
    seed は場面の ID なので、同じ指示文なら同じ絵になる。**場面の英文がサービスに送られる**。無料のサービスなので、遅い・失敗することがある（失敗したら前の絵を残す）。
    「絵のない○場面を自動で作る」で、まとめて順に作れる
  - 絵は自分の場面のものだけ見られる・変えられる（`GET /api/scenes/[id]/image`）。単語帳を消すと場面と絵も消える。
    公開した単語帳を取り込んでも、絵はコピーしない（取り込んだ人が開いたときに、新しく場面を作る）

## 7. 統計（`app/stats/page.js`）

すべて自分の単語帳だけを集計する。
- 覚え具合の区分ごとの枚数と割合、単語帳別の内訳
- 直近14日の、日ごとの「覚えている / 覚えていない」の回数（日本時間で区切る）
- 苦手な語: 「覚えていない」の回数が多い順に15件
- 区分ごとの語の一覧

## 8. レベル設定（`app/settings/`、`lib/levels.js`）

- 英検（3級〜1級）・TOEIC（〜400点〜900点〜）から選ぶと、語彙数の目安（2,000〜12,000語）が決まる。直接指定なら100〜30,000の整数
- 設定がなければ英検2級（5,000語）
- 保存したあとも、選んだレベル・入れた数をそのまま出す（フォームは `onSubmit` で送る。`action` で送ると、React がフォームを開いたときの値に戻してしまうため）
- 読み上げ（声・速さ・自動で読み上げ）は端末ごとに違うので、DB ではなくブラウザの localStorage に保存する

## 9. 読み上げ（`app/components/speech.js`）

- ブラウザの Web Speech API。英語の声だけを出し、効果音のような声は除く。同じ名前の声は1つにまとめる（端末内の声を優先）
- 声の選び方: 保存した声 → 自然な声（Samantha、Alex、Ava、Google US English …）→ en-US の声
- 記憶テストの自動読み上げ（`autoReadFront`。レベル設定の画面で選ぶ。このブラウザに保存）:
  カードが出たら（答えを考える表の面で）英文を読み上げる。初めは する。
  → でめくる（わかった）と読み上げを止める。答えの面では自動では読み上げない（↑ で読み上げられる）。
  カードが出るたびに読み上げる（「もう一度」で同じカードが続けて出たとき・← で前のカードに戻ったときも）。
  画面の最初の表示では設定が初めの値に見えるので、読み上げるかどうかは保存した設定（`getSpeechSettings`）で決める
- Chrome では、読み上げ中に止めた直後に読み上げると、その読み上げが消えることがある。
  止めた直後（読み上げ中のものを止めてから 80 ミリ秒の間）は、少し待ってから読み上げる。待っている間に別の読み上げ・停止が来たら、待っていた方はやめる

## 10. 単語帳の共有（`lib/sharing.js`、`app/shared/`）

自分の単語帳を公開すると、ログインしているほかのユーザーが「みんなの単語帳」（`/shared`）で見て、自分の単語帳として取り込める。

- 表示名（`users.display_name`）: アカウントの画面で決める。前後の空白を除き、30文字まで。制御文字は使えない。
  公開した単語帳に、作った人として出す。**メールアドレスはほかの人に見せない**。公開中の単語帳がある間は空にできない
  ヘッダーの右上にも、メールアドレスではなく表示名を出す（決めていなければ「アカウント」）
- 公開する（単語帳の編集の画面、`setDeckPublished`）: 表示名と、1枚以上のカードが要る。`decks.published_at` に公開した日時を入れる
  （公開中にもう一度押しても変えない）。公開をやめると NULL。自分の単語帳だけ
- みんなの単語帳（`listPublicDecks`）: 公開中の単語帳を、新しく公開した順に。単語帳の名前・表示名・公開日・枚数・タグ。
  自分の単語帳には「自分の単語帳」、取り込んだことがあれば「取り込みずみ」と出す
- 単語帳の中身（`/shared/[id]`、`getPublicDeck`）: カードの例文・和訳・覚えたい語・裏のメモ。公開していない単語帳は 404。
  持ち主の学習の状態は見せない
- 取り込む（`copyPublicDeck`）: **その時点の内容をコピー**して、取り込んだ人の新しい単語帳にする（1つのトランザクション）
  - コピーするもの: 単語帳の名前・動画・字幕・AI で整えた文・物語の語、タグ、カードの例文・裏・解説（和訳・意味・例文・豆知識）・動画の時刻、覚えたい語
  - コピーしないもの: 記憶テストの状態（未学習から始める）、学習の記録、公開の状態
  - 元の単語帳とはつながらない。あとで元を変えても・公開をやめても・消しても、コピーは変わらない
  - 取り込み元は `decks.source_deck_id` に残す（「取り込みずみ」の表示用。元を消すと NULL）。もう一度取り込むと、別の単語帳になる
  - 自分の単語帳・公開していない単語帳は取り込めない
- **ほかの人の単語帳（動画・字幕・カード）を使えるのは、本人が公開したものだけ。** 入り口はこの「みんなの単語帳」ひとつ。
  前は「動画を探す」（ほかの人が字幕を入れた動画を、自分のレベルに合う順に出す画面）があったが、
  公開していない単語帳の動画も出していて、字幕も渡せなかったので、なくした（マイグレーション 020 で `videos` テーブルも消した）

## 11. ホームページ（`app/landing/`）

ログインしていない人がトップ（`/`）を開くと、アプリの紹介を出す（ログインしていれば単語帳の一覧）。

- 内容: はじめの画面（キャッチコピーと「無料で始める」）、よくある悩み、i+1 の説明、使い方の4ステップ、機能、1日の流れ、よくある質問、最後の呼びかけ
- 見本のカード（`DemoCard.js`）: 学習の画面と同じ流れ（答えを見る → 覚えている / 覚えていない）を、決まった3枚でさわれる。DB には何も保存しない
- アプリでできることだけを書く。利用者の数・声などの数字は作らない
- 色は `.lp` の中だけで決める（`landing.css`）。ダークモード・スマートフォンの幅に対応


## 12. 勉強時間（`lib/studyTime.js`、`lib/studyClock.js`）

ボキャビルしながらリスニング力を鍛えるために、**単語を覚えた時間**と**リスニングの時間**を記録して、統計の画面に出す。

- 単語（`vocab`）: 記憶テストの画面（`useVocabTimer`）で、操作（キー・クリック・タッチ・スクロール）があった間を数える。
  最後の操作から2分を超えた分（席を外したとき）、ほかのタブに移っている間、動画を再生している間、全部終わったあとは数えない
- リスニング（`listening`）: アプリの中の動画プレーヤー（`app/components/VideoPlayer.js`）で、**再生している間**を数える。
  一時停止・読み込み中・終わったあとは数えない。YouTube の IFrame Player API（API キー不要、`youtube-nocookie.com`）を使う
  - 単語帳の画面: 単語帳の動画をその場で再生する。カードの「▶ 動画のこの場面」は、この動画のカードならプレーヤーをその時刻から再生する
  - 記憶テストの答えの面: 「▶ 動画のこの場面」を押すと、カードの下で、その時刻から再生する。別のタブで見たいときは「YouTube で開く」
  - 物語のスライドの自動再生（読み上げ）も、リスニングとして数える（6）
  - 持ち主がほかのサイトでの再生を止めている動画は再生できないので、YouTube へのリンクと、手で足す案内を出す
  - **別のタブや YouTube のアプリで見た時間は数えられない**（アプリから分からない）。統計の画面で手で足す
- 送り方: 30秒ごと・画面を隠したとき・閉じたとき・画面を移るときに、たまった秒数を `POST /api/study-time` に送る
  （閉じるときにも届くよう `navigator.sendBeacon`）。1回 600 秒まで。ほかのサイトからの送信（Origin が違う）は受け付けない。
  単語帳は自分のものだけ（他人の単語帳の ID なら記録しない）
- 手で足す（統計の画面）: 種類（単語 / リスニング）と分（1〜600）。今日の分として入る。手で足した記録は、新しい順に10件出し、取り消せる（自分の、手で足したものだけ）
- 統計の画面: 今日・直近7日の単語とリスニング、これまでの合計、直近14日の日ごとの積み上げ棒（単語 = 青、リスニング = だいだい）と表、単語帳別の時間。
  日は日本時間で区切る。カードがなくても出す

## 13. はじめの4ステップ（`lib/onboarding.js`、`app/Onboarding.js`）

新しく登録した人が迷わないよう、ログインしたトップの単語帳の一覧の上に、使い方の順に4つのステップを出す。

| ステップ | 終わったとみなす条件 | ボタンの行き先 |
| --- | --- | --- |
| 1. 自分のレベルを決める | `settings` に行がある（レベル設定を保存した） | `/settings` |
| 2. 動画を選んで、単語帳を作る | 単語帳が1つ以上ある | `/decks/new`（新しい単語帳） |
| 3. 字幕を貼って、覚えたい文を選ぶ | カードが1枚以上ある | 動画の単語帳のうち最初に作ったものの取り込み（`/decks/[id]/import`）。物語の単語帳は除く。単語帳がなければボタンなし |
| 4. 記憶テストをやってみる | 「覚えている / 覚えていない」の記録（`review_logs`）が1つ以上ある | カードのある単語帳のうち最初に作ったものの学習（`/decks/[id]/study`）。なければボタンなし |

- 終わったかどうかは、そのユーザーのデータを見て決める（利用者がチェックを付ける必要はない）。他人のデータは見ない
- 終わったステップは ✓ と取り消し線。まだ終わっていない最初のステップを目立たせる
- 4つとも終わるか、「閉じる」を押すと出なくなる（`users.onboarding_dismissed_at`。別の端末でも出ない）
- 前からのユーザーは、すでに4つとも終わっていれば出ない
- ステップの途中（欄が出ている間）だけ、ほかの画面も次に進みやすくする
  - レベル設定: 保存したあとに「次へ：動画を選んで、単語帳を作る →」（トップへ）を出す。画面の上に「← 単語帳の一覧」もある（いつでも）
  - 新しい単語帳: 画面の上に、YouTube の URL をコピーして貼る手順（ステップ2）を出す
  - 単語帳を作ったら、字幕を入れていなくても、そのまま字幕を貼る画面（`/decks/[id]/import`、ステップ3）へ移る（ふだんは単語帳の画面へ）

## 14. 字幕をコピーする方法（`app/decks/[id]/import/CaptionHelp.js`）

字幕から例文を追加する画面の上に、「YouTube の字幕をコピーする方法」（文字起こしを表示 → 選択してコピー → 貼り付け）を出す。

- はじめは開いた状態で、枠で囲んで出す。右上に「閉じる」
- 「閉じる」を押すと、その場で1行だけ（押すと開く）になる。閉じたことはブラウザの Cookie（`flashcard_caption_help=closed`、1年）に覚え、
  次からも1行だけで出す。サーバーが Cookie を読んで出し分けるので、開いたあとに表示が変わることはない
- Cookie なので、別のブラウザ・端末では、またはじめは開いて出る
