# flashcard-app

暗記カードアプリ。Next.js と PostgreSQL を Docker で動かします（Mac に Node.js を入れる必要はありません）。

## はじめて使うとき（セットアップ）

Docker Desktop を入れて起動したうえで、次を実行します（詳しくは [docs/setup.md](docs/setup.md)。インターネットに無料で公開するときは [docs/deploy.md](docs/deploy.md)）。

| Windows | Mac / Linux |
| --- | --- |
| `setup.cmd` をダブルクリック | `./setup.sh` |

確認・設定・起動・単体テストでの動作確認までを自動で行います。何度実行してもデータは消えません。

## 起動・停止

```bash
docker compose up -d        # 起動（初回はビルドするので少し時間がかかります）
```
起動したら http://localhost:3000 を開きます。

```bash
docker compose logs -f app  # アプリのログを見る（Ctrl+C で抜ける）
docker compose down         # 停止（DB のデータは残ります）
```

## ユーザー登録・ログイン

デッキ・カード・学習記録・レベル設定・「知ってる」の単語は、ユーザーごとに分かれます。

ログインしていないで http://localhost:3000 を開くと、アプリを紹介するホームページが出ます（「無料で始める」から登録）。

1. http://localhost:3000/signup でメールアドレスとパスワード（8文字以上）を入れる
2. 届いたメールのリンクを開くと登録が完了し、そのままログインする（リンクは24時間有効）

- 開発中は、メールは外に送らず **開発用の受信箱 http://localhost:8025**（Mailpit）に届きます
- 本物のメールを送るときは、`.env.example` を `.env` にコピーして SMTP の設定（Gmail ならアプリ パスワード）を書き、`docker compose up -d`
- ユーザー管理を入れる前のデータは、**最初に登録を完了したユーザー** が引き継ぎます
- パスワードを忘れたら、ログイン画面の「パスワードを忘れた」からメールで再設定（リンクは1時間有効）。確認メールが届かないときは「送り直す」から再送できます
- 右上の「ログアウト」でログアウト。右上の表示名（決めていなければ「アカウント」）を押すと、表示名とパスワードを変更できます

## よく使う操作

| やりたいこと | コマンド |
| --- | --- |
| パッケージを追加 | `docker compose exec app npm install <パッケージ名>` のあと `docker compose up -d --build -V` |
| DB に入って SQL を打つ | `docker compose exec db psql -U flashcard` |
| DB を初期状態に戻す | `docker compose down -v` → `docker compose up -d`（**データは消えます**） |
| DB のテーブルを変更する | `db/migrations/` に `003_xxx.sql` のように次の番号で SQL を足す（アプリの起動時に自動で当たる） |
| 単体テストを実行する | `docker compose exec app npm test`（コミットの前にも自動で実行。詳しくは `docs/testing.md`） |
| 単体テストを1件ずつ画面で実行する | `docker compose exec app npm run test:ui` → http://localhost:3100 |
| 画面のテストも実行して、スクリーンショット付きのテスト結果レポートを作る | `docker compose run --rm e2e` → `reports/<日時>/index.html`（初回はダウンロードに数分） |
| 販売促進用のパンフレット（PDF）を作り直す | 画面写真: `docker compose run --rm e2e npx playwright test -c promo/playwright.config.mjs`、PDF: `docker compose run --rm e2e node promo/make-pdf.mjs` → `promo/flashcard-brochure.pdf`（`-e PROMO_URL=…` でアプリの URL を載せる。文章は `promo/brochure.html`） |

## 字幕から例文カードを作る

1. 「レベル設定」で、英検の級か TOEIC の点数を選ぶ
2. トップの「＋ 新しいデッキ」で、YouTube の URL（デッキ名は動画のタイトルが自動で入る）と、字幕のテキスト（「文字起こしを表示」からコピー）を入れる
3. 作成すると、知らない語（単語またはイディオム）がちょうど1つの文が並ぶので、覚えたい文を選んで登録する

URL と字幕はデッキに保存されるので、次からはデッキの「保存した字幕から例文を追加」を押すだけです。
知っている語は「知ってる」ボタンで追加でき、例文カードに登録した語も「知っている」として扱われます。
イディオムは `data/idioms.tsv` のリストで判定します。

## 段階的に動画を理解する（i+1 → i+2 → i+3）

字幕の文を、知らない語の数で分けて、やさしい段階から覚えていきます。

- **知っている語**: レベル内の語、「知ってる」を押した語、学習で「覚えた」（3回続けて「覚えている」）語
- **学習中の語**: カードにしたが、まだ「覚えた」になっていない語。その語を含む文は、覚えるまで新しい候補に出しません
- 取り込み画面の「i+1 / i+2 / i+3」は、新しく覚える語が 1〜3 個の文です。候補がある一番やさしい段階が自動で選ばれます
- i+2・i+3 の文は、覚えたい語を2〜3個まとめた1枚のカードになります（すべて強調し、それぞれの意味を付けます）
- デッキ画面の「この動画の理解度」は、字幕のすべての文のうち、全部わかる文の割合です。100% でその動画はクリアです

## タグ

デッキには分類タグ（例: 英語、ビジネス）を付けられます（作成・編集の画面で、入力して Enter）。
トップのデッキ一覧の「絞り込み」欄にタグを足していくと、そのタグをすべて持つデッキだけに絞り込めます（AND 条件）。

## 学習（記憶テスト）

デッキの「学習する」から、カードを1枚ずつ表示します。「答えを見る」で裏面を出し、「覚えている / 覚えていない」を押すと次のカードへ進みます
（キーボード: 表の面では → で答えを見る・← で前のカードに戻る、答えの面では ← で覚えていない・→ で覚えている）。
前のカードに戻ると、そのカードへの答えは取り消され、答え直せます。

- 覚えていたカードは、1日後 → 3日後 → 1週間後 → 2週間後 → 1か月後 → 2か月後 と、間隔をあけて出てきます（その日の朝4時から出ます。日付は朝4時に変わるものとして数えます）。
- 覚えていなかったカードは、その回の最後にもう一度出て、次の日からまた出てきます。
- その日に出すカードがないときは「全カードを学習する」で全部を復習できます。

## 覚えた単語で物語を作る

トップの「覚えた単語で物語を作る」から、覚えた（または学習中の）単語を使った短い英語の物語を、チャット AI に書いてもらえます。

1. 使う単語（覚えた語 / 学習中の語 / 両方、デッキ、数）、長さ、テーマを選んで、プロンプトを作る
2. チャット AI に送り、答え（「タイトル:」と「[1] 英文」の行）を貼り付ける
3. 「物語: タイトル」のデッキ（タグ「物語」）ができ、選んだ単語が入っている文がカードになる

物語のデッキでは、本文を通して読めます（使った単語を強調、和訳の表示切り替え、全文の読み上げ、文をクリックでその文を読み上げ）。

## 読み上げ

ブラウザの読み上げ機能（Web Speech API）で、英文を読み上げます（無料・オフラインでも動く）。

- 学習画面の表の面、カードの一覧、例文、取り込みの候補に、読み上げボタン（ふつう / ゆっくり）があります
- 学習画面（パソコン）では ↑ キーで読み上げ、Shift+↑ でゆっくり読み上げます
- 「レベル設定」の「読み上げ」で、声・速さ・「カードが出たら自動で読み上げる」を選べます（このブラウザに保存）

## 統計

上部の「統計」から、覚え具合を見られます。

- **覚え具合**: 覚えた（3回続けて「覚えている」）/ 覚え中 / 覚えていない（最後に「覚えていない」）/ 未学習 の枚数と割合
- **デッキ別**: デッキごとの内訳（横棒グラフと表）
- **学習の記録**: 直近14日の、日ごとの「覚えている / 覚えていない」の回数
- **苦手な語**: 「覚えていない」を押した回数が多い語
- **区分ごとの語**: 覚えた語・覚えていない語などの一覧

## デッキを共有する（みんなのデッキ）

自分のデッキを公開すると、ほかのユーザーが自分のデッキとして取り込めます。

1. 上部のメールアドレス（アカウント）で **表示名** を決める（公開したデッキに、作った人として出ます。メールアドレスは見えません）
2. デッキの「デッキを編集・削除」の下の **「このデッキを公開する」** を押す（「公開をやめる」でいつでも戻せます）
3. ほかの人は上部の **「みんなのデッキ」** から開いて、「自分のデッキに取り込む」を押す

取り込むと、その時点のカード・解説・タグがコピーされます。学習は最初からで、元のデッキをあとで変えてもコピーは変わりません。

## チャット AI との連携（無料）

API は使わず、claude.ai などのチャット AI にプロンプトを貼り付けて、その答えをアプリに取り込みます。

- **字幕を完結した文に整える**: 取り込み画面の「チャット AI で文を整える」から（句読点のない字幕のときは最初から開いています）。
  句読点を付けるほか、フィラー（um, uh）や言葉の重なり・言い直しを消し、明らかな聞き間違いを直します。
  リスニングの練習にも使うので、言い換えや文法の修正はしません（話された言葉のまま）。
  言葉を消したり直したりした文には元の字幕も付き、候補の下に「元の字幕」として表示されます。
  取り込むと、登録済みのカードも、時刻と言葉の重なりで対応する文を探して、例文・和訳・語句の意味・和訳の強調を上書きします。
  プロンプトをコピーしてチャット AI に送り、答え（`[0:06] 文` の行）を貼り付けて取り込みます。
  整えた文はデッキに保存され、途中で切れていた登録済みのカードも完結した文に置き換わります。
- **カードの解説を作る**: デッキの画面の「チャット AI で解説を作る」で、解説のないカード（一度に20枚まで）のプロンプトを作ります。
  答え（`### 番号` で始まる、和訳・意味・例文・豆知識）を貼り付けて取り込みます。

## 設計書・テスト

- 設計書は `docs/`（入口は [docs/README.md](docs/README.md)）。コードを変えたら同じコミットで直す
- 単体テストは `test/`（Vitest）。テスト用の DB `flashcard_unittest` を毎回作り直して使うので、開発中のデータには触れない
- コミット前のテストは、セットアップのスクリプトが有効にする（手でやるなら `git config core.hooksPath .githooks`）

## 構成

- `app/` … 画面（Next.js App Router）
- `lib/db.js` … DB 接続
- `lib/auth.js` / `middleware.js` … ログインの状態（セッション）と、ログインしていないときの転送
- `lib/accounts.js` / `lib/password.js` / `lib/mail.js` … 登録・パスワード再設定のメール、パスワードのハッシュ化、メール送信
- `db/migrations/` … テーブルの変更履歴。`scripts/migrate.mjs` が、まだ当てていないものを番号順に当てる
- `lib/transcript.js` … 字幕を文に分けて、i+1 の文（知らない単語がちょうど1つ）を探す
- `lib/vocab.js` … 単語の原形と頻出順位
- `lib/idioms.js` … 文の中のイディオム・句動詞を見つける
- `lib/sentences.js` … 字幕を文に整えるプロンプトと、チャット AI の答えの読み取り
- `lib/cardPrompts.js` … カードの解説のプロンプトと、チャット AI の答えの読み取り
- `lib/review.js` … 記憶テストの出題間隔と、覚え具合の区分
- `lib/videoTitle.js` … YouTube の動画タイトルの取得（公開の oEmbed を使用）
- `data/en-words.txt` … 単語の頻出度リスト（出典とライセンスは `data/README.md`）
- `compose.yaml` / `Dockerfile` … Docker の設定（app・db・mailpit）
- `test/` / `vitest.config.mjs` / `.githooks/pre-commit` … 単体テストと、コミット前の自動実行
- `tools/test-runner/` … ブラウザで単体テストを1件ずつ実行するツール
- `docs/` … 設計書
- `setup.sh` / `setup.ps1` / `setup.cmd` … セットアップのスクリプト（Mac・Linux / Windows）

コードを保存すると、ブラウザに自動で反映されます。
